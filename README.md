# G2 launcher

G2 Launcher is a local-first app library and launcher for Even Realities G2 smart glasses. It lets users import compatible G2 app packages, keep them stored locally inside the launcher, and launch them directly from a simple glasses-first interface.
The mobile WebView is used for importing, managing, sorting, and launching apps, while the G2 display provides a minimal high-contrast HUD optimized for R1 ring and G2 touchpad navigation. Swipe selects apps, single tap launches, and double tap exits the launcher from the main menu. When an imported app is running, gestures are passed through to that app so it can handle its own navigation.
G2 Launcher supports persistent local storage, manual language selection, and compatibility routing for common Even Hub capabilities such as location, camera, album access, microphone, device info, and G2 container updates. Imported apps run inside G2 Launcher’s local runtime and do not modify the native Even Hub plugin list.
Designed for users and developers who want a clean, customizable launcher for their own G2 app collection.
